# DFA-GPT2 Dataset

This repository contains the dataset used in the DFA-GPT2 study.

## Dataset Description

The dataset consists of two subsets:

- `train.jsonl`: Training dataset (10,000 samples).
- `test.jsonl`: Test dataset (1,000 samples).

The files are provided in JSON Lines (JSONL) format, with one sample per line.

## Data Format

Each line contains a DFA-related input and its corresponding target output, including the automaton information and simulation task.

## Usage

The dataset can be downloaded directly from this repository and used for DFA simulation and language model experiments.
